# FinTech-Risk-Assessment
Simulated ISO/IEC 27001:2022 information security risk assessment and risk treatment project for a fictional FinTech company, PayBridge Technologies Pvt Ltd.
The project demonstrates the fundamentals of information asset identification, information security risk assessment, risk treatment and ISO 27001:2022 Annex A control mapping.

Company: PayBridge Technologies Pvt Ltd

Industry: Financial Technology (FinTech)

Location: Bengaluru, India

Employees: 60

Services: Online payment processing

Infrastructure: AWS Cloud

Project Objectives
Identify and classify information assets.
Identify potential information security risks.
Assess risks based on likelihood and impact.
Develop a risk treatment plan.
Map identified risks to relevant ISO 27001:2022 Annex A controls.

Disclaimer : This is a fictional portfolio project created for educational purposes. All company details, assets and risk scenarios are simulated. It does not represent an actual ISO 27001 implementation, audit or certification.
